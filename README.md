# 开园啦！

手机竖屏 3D 游乐园经营 Demo。共有 10 关，每关营业 2–5 天。按本关游客累计营收评星，1 星目标从第一关的 3,200 金币逐关提高至第十关的 20,800 金币。达到 125% 或 150% 的目标分别获得 2 星和 3 星。1 星解锁下一关，浏览器会保存每关的历史最高星级。

第 1 关走直道，营业 2 天。第 2–3 关有两条支路，营业 3 天。第 4–6 关有三条支路，营业 4 天。第 7–10 关先分两路，再各自分叉，营业 5 天。第 4 关开始出现 BUFF。点左上角的图标可以查看关卡特性和已购买的 BUFF。

第 1 关带 2,100 金币开局，商店只出售旋转茶杯、飞椅和水上滑梯。依次购买并摆放飞椅、水上滑梯、旋转茶杯可让三座设施接连触发。滑梯与茶杯在这一关分别需要 15 点刺激和 20 点欢乐。

商店每次随机上架最多三件商品。拖动新设施到空格，或点卡再点空格，可以购买并摆放。点价格可以先存进仓库。重复购买同类设施会自动升级，由 Lv.1 的 50% 效果起每次加 10 个百分点，Lv.6 达到 100%。购买 BUFF 会立即生效，同类一关只售一次。满级设施也会退出本关的商品池。

当天第一次刷新花费 200 金币，之后依次为 300、400……隔天重置。剩余金币按开园时的余额计算 10% 利息，下一天到账。商品价格每过一天上涨 5%。刷新、购物与利息只影响可用金币。

游客头顶的圆环显示欢乐、刺激、幸福的合计进度。低于 50 分、达到 50 分、达到 100 分分别结算 100、150、200 金币。开心游客超过 100 分的部分，每满 1 分多赚 1 金币。结算在「开心」下方单独显示这笔收入。摆位和 BUFF 会改变开园前的客流和营收预估。

「导览旗」会让游客更偏向能玩到更多设施的支路。「集章卡」奖励同一段支路内成功体验两座设施的游客。设施顺序也会影响「接力派对」与「首尾联票」。

```powershell
npm.cmd install
npm.cmd run verify:levels
npm.cmd run dev
```

访问 http://127.0.0.1:4173/ 。完整 3D 画面需要 WebGL 2。`npm.cmd run verify:levels` 复跑十关的三星方案，检查抽卡、购买、金币、摆位与游客结算。`npm.cmd run build` 生成可发布到 GitHub Pages 的静态网站。
